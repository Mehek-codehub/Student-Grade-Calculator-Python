# 🎓 Student Grade Calculator

A beginner-friendly Python project that calculates a student's grade based on marks entered by the user. The program validates the input, assigns a grade using `if-elif-else` statements, and displays an encouraging message.

---

## 📌 Project Overview

This project was developed as part of Python Week 2 practice to understand decision-making, loops, functions, and error handling.

The application:
- Accepts student name
- Accepts marks (0–100)
- Validates user input
- Calculates grade
- Displays encouraging messages


## 🎯 Objectives

- Learn Python if-elif-else statements
- Practice while loops
- Create reusable functions
- Perform input validation
- Handle exceptions using try-except


## 🚀 Features

- Student name input
- Marks validation (0–100)
- Grade calculation
- Encouraging messages
- Exception handling
- User-friendly output


## 📊 Grading Logic

| Marks | Grade |
|-------:|:-----:|
| 90–100 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| 0–59 | F |
